عنوان نمونه کار

۱۲ اردیبهشت ۱۴۰۵ تیم فنی Aspdotnetkar نام گروه نمونه کار ۴٬۲۱۰ بازدید

اگر تازه ساخت سایت با ASP.NET Core را شروع کرده‌اید، دیر یا زود به ابزاری برای ارتباط با پایگاه‌داده نیاز پیدا می‌کنید. Entity Framework Core یا به‌اختصار EF Core همان ابزار است: یک ORM (Object-Relational Mapper) که به شما اجازه می‌دهد به‌جای نوشتن دستی کوئری‌های SQL، با کلاس‌ها و اشیای #C با پایگاه‌داده کار کنید.

۱. EF Core دقیقاً چه کاری انجام می‌دهد؟

وقتی از EF Core استفاده می‌کنید، هر جدول در پایگاه‌داده معادل یک کلاس در پروژه‌ی شماست و هر سطر آن جدول، یک نمونه از همان کلاس. EF Core مسئول ساخت کوئری SQL از روی کدهای #C، اجرای آن، و برگرداندن نتیجه به‌شکل اشیای آماده است. نتیجه‌ی این کار، کدی خواناتر و کمتر مستعد خطاست؛ چیزی که در پروژه‌های واقعی که تیم Aspdotnetkar برای مشتریان می‌سازد، اهمیت زیادی دارد.

۲. نصب و راه‌اندازی

برای شروع، دو پکیج زیر را به پروژه‌ی ASP.NET Core خود اضافه کنید. پکیج اول درایور ارتباط با SQL Server است و پکیج دوم ابزارهای خط‌فرمان برای مدیریت مایگریشن‌ها را فراهم می‌کند.

Terminal
dotnet add package Microsoft.EntityFrameworkCore.SqlServer
dotnet add package Microsoft.EntityFrameworkCore.Tools

۳. تعریف مدل و کلاس Context

کلاس DbContext پل ارتباطی میان کدهای شما و پایگاه‌داده است. در آن، هر جدولی که نیاز دارید را به‌شکل یک DbSet تعریف می‌کنید:

AppDbContext.cs
public class AppDbContext : DbContext
{
    public AppDbContext(DbContextOptions<AppDbContext> options)
        : base(options) { }

    public DbSet<Product> Products => Set<Product>();
}

۴. اجرای اولین Migration

مایگریشن‌ها به EF Core می‌گویند ساختار پایگاه‌داده باید چگونه تغییر کند تا با مدل‌های #C شما هماهنگ شود. دستور زیر را در ترمینال پروژه اجرا کنید:

Terminal
dotnet ef migrations add InitialCreate
dotnet ef database update
برای کوئری‌هایی که فقط قرار است داده را نمایش دهید و قصد ویرایش ندارید، حتماً از AsNoTracking() استفاده کنید؛ این کار با حذف ردیابی تغییرات، سرعت کوئری را به‌طور محسوسی افزایش می‌دهد.

۵. نوشتن اولین کوئری

حالا که مدل و پایگاه‌داده آماده است، می‌توانید با LINQ کوئری بنویسید؛ درست مثل کار با یک لیست معمولی در #C:

ProductService.cs
var cheapProducts = await context.Products
    .AsNoTracking()
    .Where(p => p.Price < 500000)
    .OrderBy(p => p.Price)
    .ToListAsync();

جمع‌بندی

  • EF Core نیاز به نوشتن دستی SQL را در بیشتر موقعیت‌های روزمره از بین می‌برد.
  • مدل‌های #C همان ساختار جدول‌های پایگاه‌داده را نمایش می‌دهند.
  • مایگریشن‌ها تغییرات مدل را به‌صورت ایمن روی پایگاه‌داده اعمال می‌کنند.
  • برای کوئری‌های فقط‌خواندنی، همیشه از AsNoTracking() استفاده کنید.

اگر برای پیاده‌سازی این موارد در پروژه‌ی خودتان به کمک نیاز دارید، تیم Aspdotnetkar آماده‌ی همراهی در تمام مراحل، از طراحی پایگاه‌داده تا استقرار نهایی سایت است.
